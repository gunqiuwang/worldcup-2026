# WorldCup 2026 — 全面优化计划

## 目标
将现有世界杯预测分析平台从 MVP 升级为功能完整、UI 精致的生产级应用。

## 当前状态
- React + Vite + Tailwind + framer-motion
- 72 场比赛数据（美式赔率）
- 48 队国旗 + ESPN 徽章
- 已有：赛程页、积分榜、赔率页（空壳）、数据中心（爆冷/赔率异动/淘汰赛预测）

## 阶段六：懒加载优化

### 步骤
1. Dashboard 页面的 6 个模块用 `React.lazy` + `Suspense` 加载
2. 首屏只加载「今日焦点」+「分析维度」
3. 滚动到可视区域时加载其余模块（IntersectionObserver）
4. 加载时显示骨架屏

### 验收标准
- [ ] 首屏加载时间 < 2 秒（4G 网络）
- [ ] 滚动时模块平滑加载，无闪烁
- [ ] 骨架屏与实际模块尺寸一致
- [ ] Lighthouse 性能分 > 80

## 阶段七：实时比分接入（ESPN API）

### 步骤
1. 新建 `src/services/espnApi.ts`
2. 使用 ESPN 公开 API：`https://site.api.espn.com/apis/site/v2/sports/soccer/fifa.world/scoreboard`
3. 轮询间隔：30 秒（比赛中）/ 5 分钟（未开始）
4. 更新 SCHEDULE 中的 score、status 字段
5. 进球时播放动画效果 + 通知提示

### 验收标准
- [ ] 比赛进行中时，比分每 30 秒自动刷新
- [ ] 进球时 MatchCard 有高亮动画
- [ ] 状态从 scheduled → live → finished 自动切换
- [ ] 网络失败时降级到缓存数据，不崩溃
- [ ] 未开始比赛不发请求（节省流量）

## 风险
- 阶段四 SVG 地图体积可能较大 → 用简化版地图，压缩后 < 20KB
- 阶段七 ESPN API 可能有 CORS 限制 → 用 Cloudflare Workers 代理
- 阶段六 IntersectionObserver 在旧浏览器不兼容 → 加 polyfill 或降级为立即加载
